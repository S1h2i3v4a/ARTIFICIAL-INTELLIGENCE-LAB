## 🛠 Compilation and Execution Instructions

### Prerequisites
- **Java SE Development Kit (JDK 21 LTS or higher)**
- **Terminal / PowerShell / Command Prompt**

### 1. Compile All Practicals
From the project root directory, run:
```bash
javac src/*.java
```

### 2. Execute an Individual Practical
Run any practical class using the `-cp src` classpath flag:
```bash
# Example: Run Practical 01 (BFS)
java -cp src Practical01

# Example: Run Practical 03 (8-Puzzle A* Search)
java -cp src Practical03

# Example: Run Practical 18 (Minimax with Alpha-Beta Pruning)
java -cp src Practical18
```

### 3. Batch Execution
To execute all 22 practicals and generate output logs:
```powershell
1..22 | ForEach-Object {
    $num = "{0:D2}" -f $_
    java -cp src "Practical$num" | Out-File -FilePath "outputs/practical_${num}_output.txt" -Encoding utf8
}
```
